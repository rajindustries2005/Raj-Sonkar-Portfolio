# Raj Sonkar — Portfolio

My personal portfolio showcases my work in AI and machine learning, workflow automation, and SAP functional consulting. It includes my projects, internships, technical skills, education, and certifications.

## Features

- Interactive 3D neural network that demonstrates a forward pass
- Animated workflow for my Python personal assistant, built with Selenium and SQLite
- English voice narration with **Listen to portfolio** and **Stop narration** controls
- Light and dark themes
- Downloadable CV and links to my professional profiles

## Run locally

Extract the portfolio ZIP and open `index.html` in your browser. Keep the HTML, CSS, JavaScript, background image, and CV together. The site is built with plain HTML, CSS, and JavaScript and runs without a build step.

## Deploy on GitHub Pages

1. Upload the extracted portfolio files to the root of your repository alongside this `README.md`.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`, then click **Save**.
5. Open the published URL shown under **Settings → Pages**.

If your browser blocks automatic narration, click **Listen to portfolio** to start it.
